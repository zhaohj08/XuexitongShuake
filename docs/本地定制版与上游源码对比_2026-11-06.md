## 1. 一句话结论

**本地不是「给上游打了几个补丁」，而是基于上游 `26.10.13`（2026-10-14 大版本）源码快照的深度重构分支：**
新增 15 个模块、改写 28 个同名文件、核心文件行数普遍翻 1.5～3 倍，
并配套 16 个测试套件、21 个版本节的工作日志与单文件打包/自检体系。
而上游自 10-14 之后只改过 4 个文件，其中**只有 1 行是代码**（清空高德 API Key）。
作者 26.11.04 的新功能（复习模式 / 问卷随机答题 / 邮箱提醒）只发布在 Release 的 exe 里，**没有可对比、可合入的源码**。

## 5. 逐主题对比区别

### 5.1 路径与数据目录（3.5、3.7、4.4、4.6）

- 上游：`requirements.txt` 缺 `numpy` / `pycryptodome`；`main.py` 登录 URL 少斜杠、一处非法 XPath；数据散落在 `task/`。
- 本地：新增 `core/paths.py`（226 行），区分只读资源 / 可写数据 / 账号 HOME；`data_or_asset()` 优先数据副本；
  `migrate_portable_install()` 迁移旧版数据并写 `.migrated`；`migrate_legacy_names()` 兼容旧记录名与「正在学习」标记。
- **行为变化**：exe 可放只读目录、桌面、U 盘；换电脑数据不丢；源码运行仍回落项目 `task/`，开发数据互不干扰。

### 5.2 日志与可观测性（4.17、4.32、26.10.31.1537 / 1558 / 26.11.05.1911）

- 上游：无独立主日志；日志每行重复两遍；出问题只能靠界面截图。
- 本地：`core/applog.py`（140 行）写 `logs/程序日志.log`，启动块含版本 / pid / 平台 / 路径，
  INFO/WARN/ERROR/CHILD/UI 带毫秒时间戳，8 MB 轮转、线程锁；`core/runner.py` 把子进程全部输出落到主日志与账号明细；
  `task/xxt/storage.py` 签到日志加时间戳；`core/log_export.py`（523 行）界面一键导出单日 zip。
- **行为变化**：排查从「看截图」变成「读完整时间线」；发给作者只需一个文件，且手机号/密码/API Key 自动脱敏。

### 5.3 浏览器驱动与会话（4.2、4.5、4.12、26.10.31.1228）

- 上游：驱动路径靠手填；页面异常被统一显示成「❌ 浏览器启动失败: (No symbol)」；切窗口不等标题，`window_handles=None` 会二次报错。
- 本地：`core/driver.py`（300 行）探测浏览器版本、多级候选、CDN 下载；`core/browser.py` 的 `press_key/press_combo/press_escape/keep_awake` 走 CDP；
  `main.py` 增加 `_error_brief()` 异常分诊、`turn_page` 轮询等待、`_wait_element(s)`、`_close_course_tab()`；
  规避 `switch_to.frame(None)` 静默失效、`execute_script` 必须 `return` 等坑（第 8 节踩坑清单）。
- **行为变化**：新电脑首跑不再 `NoSuchDriverException`；页面问题不再被误报为浏览器启动失败。

### 5.4 课程推进与页面识别 ★（4.9–4.23、4.28、4.30、4.31）

这是本地改动最集中的部分，也是 2026-11-05 用户报障的主线：

| 问题（上游 / 早期本地） | 本地修复 | 依据 |
|---|---|---|
| 「我学的课」点不进 / 点到 `<li>` 没反应 / 点了没跳还谎报已进入 | `_click_text_keyword`、`_collect_course_cards`、`_click_course_tab`、关键字兼容 | 4.16、4.18–4.20 |
| 翻页「三态」误判、未知页面原地死循环 | `_wait_page_changed` + 三态翻页 + 卡页计数 + `UNKNOWN_REFRESH_LIMIT` | 4.10、4.15 |
| 遇见章节测验直接跳过 | 选择器放宽 `src^=`、滚动容错、class 包含匹配、完成判定只看测验自身 | 4.9、4.13 |
| 认不出的页面反复刷新、无证据 | 「截图 + 直接下一节」，任何错误都留 `save_diagnostic_screenshot()` | 4.23 |
| 被打回的空壳页空转、新版学习页无 id iframe | 空壳页识别 + iframe 兜底 | 4.28 |
| **整门课被误判「学完」** | `_content_signature()` 指纹原本不含 URL/chapterId，所有视频页指纹相同，`no_progress` 跨 38 分钟/多章节累积到 3 就 `return 'done'`。本地新增 `_page_identity()`（提取 chapterId/courseId/clazzId/knowledgeId/objectId/jobId/cardId，排序拼接，排除随机 token），改用复合指纹 `身份||内容指纹`；未识别页重置计数；达上限先 `refresh()`，仍卡住返回 `lost` 触发 `_reenter_course()`；处理器异常后重置计数；刷新后 identity 为空不误判换页 | **4.30、4.31**；日志 26.11.05.1726 / 1832 |

- **行为变化**：11-05 桌面日志里 4 次「连续 3 次页面内容没有变化，结束本课程」的误判不再发生；课程到底 / 连续 8 次找不到下一页仍正常结束。

### 5.5 答题链路与额度（3.2、3.3、4.8–4.10、4.21–4.27、7.1、7.2）

| 上游问题 | 本地做法 |
|---|---|
| 题库返回用 `eval()` | `_as_answer_list()` 改 `ast.literal_eval` |
| 批量答案按 `/` 位置回填无校验 | `_split_batch_answer()` 段数校验，对不上 `_ask_one()` 逐题兜底 |
| AI 兜底答案写缓存，错一次永久固化 | `AnswerResult.cacheable`，只缓存题库命中结果 |
| 图片题只能跳过 | `DeepSeekAskImage` 多模态作答，`_LABEL_JS` 点字母节点、不碰图片 |
| 考试/测验必须挂任务点、整章无任务点就跳过 | `require_mission=False` + `_open_first_chapter()` 从头扫 |
| 计算题被当图片题送多模态、`<li>` 误判 | 特殊题跳过判定加固（4.25、4.26） |
| 简答题疯狂消耗 API 额度、本轮最多 100 次总量上限 | `task/tool/quota.py`（142 行）改为频率限流：20 次/分钟、同题最多 2 次 |
| 视频题 AI 答案被随机分支覆盖 | 整段 AI 分支删除，固定随机穷举（**用户明确要求，不得改回**） |

### 5.6 签到子系统 ★（4.29、4.31、1475 封号分析）

- 上游：`constants.py CHECK_INTERVAL = 2`（注释却写「每 7 秒」），`monitor.py` 每轮对 24 门课各发一次 `ACTIVE_LIST`、
  并发 5 ≈ **12 次/秒 ≈ 4.3 万次/小时**；`sign_once()` 不传 `stop_event`，`parse_args()` 会被 `start.py --sign` 的额外参数拒掉；
  `storage.log` 无时间戳；`DEFAULT_AMAP_KEY` 硬编码作者的高德 Key。
- 证据（`.workbuddy-ai/memory/2026-11-05.md`）：`data/sign.log` 1258 行里 1231 行是空转的「课程列表: 24 门」，
  7 次「已启动」只有 6 次「已停止」；答题侧全部日志联网仅几百次且有 20 次/分钟限流，排除「20 万次来自答题 API」。
- 本地（4.31）：`CHECK_INTERVAL=30`，新增 `IDLE_BACKOFF_AFTER=10`、`MAX_CHECK_INTERVAL=120`、`MAX_RUNTIME=4*3600`；
  `monitor()` 空闲退避 / 到点自停 / 发现签到恢复基础间隔；`storage.log` 加时间戳；
  `sign_window.py` 抽 `_build_parser()` 改 `parse_known_args()`、`sign_once()` 传 `stop_event`、
  `_watch_parent_exit()` 父进程消失自停；4.29 支持多账号签到多选与并发状态可视化。
- **行为变化**：平台请求从 ≈4.3 万次/小时降到 30 秒起、空闲逐步退避到 120 秒、连续运行 4 小时自动停。
- **注意**：上游 11-03 已把 `DEFAULT_AMAP_KEY` 清成空串，本地仍是硬编码 Key —— 这是**唯一真冲突**，见 `上游对比与合入计划_2026-11-06.md`。

### 5.7 多账号并发（3.7、4.29、26.10.31.2313）

- 上游：账号配置、Cookie、记录、进度都是单份，全局章节锁，按键发到前台窗口。
- 本地：`core/runner.py`（251 行）每账号一个独立子进程，`XXT_HOME` 隔离数据；
  `core/config_manager.py` 重写（98→382 行）成 `global + accounts[]`，旧 `account_info.json` 自动迁移；
  `start.py` 每账号一个日志框 + 顶部下拉切换、并发启停；`gui/setting_panel.py` 账号增删/并发数/切换静默保存。
- 26.10.31.2313 另修「自动签到只签一个账号、不能选账号」与「调完并发数不知道哪几个账号在跑」。

### 5.8 GUI 与主题（3.4、4.17、4.32）

- 上游：颜色硬编码；`anchor="ns"` 在 customtkinter 6.0 下启动即崩；主窗口不可缩放；设置页小屏截断。
- 本地：`gui/theme.py`（99 行）7 套语义色板 + 间距/圆角/字体；全 GUI 去硬编码；窗口可缩放且有最小尺寸；
  设置页改 `CTkScrollableFrame`；关闭窗口先 `runner.stop_all()` 再销毁（4.17）；
  4.32 新增 `gui/log_export_dialog.py`（203 行）与主页「⇩ 导出完整日志」按钮。

### 5.9 打包、版本与自检（3.6、3.8、4.3、4.4、4.11、各打包版本节）

- 上游：无 `start.spec`、无版本资源、无自检；作者 Release 是 88 MB 的 onedir 压缩包。
- 本地：`start.spec`（85 行）单文件打包（资源打进去、数据放外面）、`start_version.txt` 写 exe 文件属性、
  `--selftest` 逐个 import 全部模块与资源并写 `selftest.log`、版本号 = 打包时刻 `YY.MM.DD.HHMM`、
  每次打包备份上一版 exe。修过「双击 exe 报 Could not create temporary directory!」、打包后缺 selenium 子模块、
  `logging.basicConfig` 二次调用失效导致报错日志不生成等事故（3.8、4.3）。
- 当前产物：`dist/start.exe` 63,575,643 字节 / 19:13:39 / `26.11.05.1911` / `--selftest` PASS。

| 场景 | 上游 master 源码 | 本地定制版 |
|---|---|---|

| 自动签到挂机 4 小时 | ≈17 万次平台请求（24 门课 × 2 秒） | 30 秒起、空闲退避到 120 秒、4 小时自动停 |

## 9. 本地仍未修、或与上游共同的遗留

来自 `AGENT_HANDOVER.md` 第 7 节与 11-05 / 11-06 工作日志：

1. 驱动获取失败只在日志里，界面没有引导。
2. 作业模式只处理第一门课；作业「自动选择」硬编码 `elements[2]`，页面一变就 `IndexError`。
3. 直播时长按「秒×60+分」解析：`1:30` 会等 30 分钟、`45:00` 只等 45 秒。
4. 签到首次使用可能调到 `input()`，窗口版无控制台会 `EOFError`（4.31 修的是 `--sign`/停止机制，此项仍待真机确认）。
5. `accounts.json` 明文存手机号 / 密码 / API Key（日志导出已脱敏，但源配置未加密）。
6. 位置签到「爬山修正」`MAX_ROUNDS=10 × MAX_WALK=100` 无总请求上限 —— 与封号同类隐患，未改。
7. P2：图文作业页未纳入 `CONTENT_TYPES`，仍会产生「无法识别」诊断截图，需真机确认判定条件。
8. 3 个真实 Edge 测试套件因本机驱动版本不匹配失败，需下载匹配驱动。
9. 单日日志导出里，无逐行时间戳的账号日志按文件 mtime 判断，跨午夜运行会整份纳入当天。
10. 关窗后签到子进程是否完全停止，尚未在那台电脑上真机验证。

用户明确「不是问题、不要再改」的（7.1）：视频内弹题固定随机作答、答题率语义、只缓存题库答案不加 TTL、已完成测验要跳过。
