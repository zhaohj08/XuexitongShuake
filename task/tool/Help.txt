一、浏览器选择相关

  1. 问：在设置页面中，浏览器如何选择？
     答：建议使用 Chrome；如果 Chrome 不可用，可以切换到 Edge。

  2. 问：浏览器驱动还需要手动下载吗？
     答：不需要。程序会先使用本机已有的驱动，其次读取程序目录或数据目录下的 drivers 文件夹，
     最后按本机浏览器版本自动下载匹配的驱动。只有自动获取失败时，才需要手动处理。

  3. 问：如何查看 Chrome / Edge 的版本号？
     答：在浏览器地址栏输入 chrome://version 或 edge://version，页面第一行就是完整版本号。

  4. 问：Chrome 驱动在哪里下载？
     答：https://googlechromelabs.github.io/chrome-for-testing/
     请下载与本机 Chrome 版本一致的 chromedriver。

  5. 问：Edge 驱动在哪里下载？
     答：https://developer.microsoft.com/microsoft-edge/tools/webdriver/
     请下载与本机 Edge 版本一致的 msedgedriver。

二、驱动地址相关

  1. 问：驱动地址是什么？
     答：它是浏览器驱动的可执行文件路径，不是浏览器本身的路径。

  2. 问：版本一致时驱动地址如何配置？
     答：在设置页面点击“选择文件”，选中 chromedriver 或 msedgedriver 可执行文件即可。

  3. 问：自动下载失败、版本又不一致怎么办？
     答：先把对应版本的驱动解压出来，放进程序同级的 drivers 文件夹（可以带子目录），
     或者在设置页面把“驱动地址”指向解压出来的驱动文件，然后重新启动程序。

三、其他设置相关

  1. 问：字体和信息设置有什么要求？
     答：字体按自己的习惯选择即可，建议开启窗口置顶。信息按实际情况填写；
     课程名称要和平台里显示的名称完全一致，建议直接复制粘贴。

  2. 问：答题如何设置？
     答：在“章节测验”里选择 DeepSeek AI（支持常见题型）。设置完务必点击保存并确认，
     再回到主页启动程序。

  3. 问：倍速应当如何设置？
     答：建议 2 倍速。倍速过高可能导致已完成的任务点被重置；运行中想改倍速需要重启程序。

  4. 问：DeepSeek API Key 怎么获取？
     答：前往 DeepSeek 开放平台注册并创建 API Key，然后在设置页填写并保存。

四、程序相关

  1. 问：点击启动后没有反应怎么办？
     答：先关闭程序，右键以管理员身份重新运行；仍然没有反应时，可以尝试直接运行主程序文件。

  2. 问：选择“不作答”时，启动后会发生什么？
     答：程序会自动打开浏览器并登录，进入课程后按设置处理视频、PPT、音频等内容，
     跳过章节测验。遇到问题可以到“报错日志”页面查看原因。

  3. 问：提示“无法加载扩展”怎么办？
     答：先确认浏览器与驱动版本一致；不一致时按上面的方法更换驱动。
     如果版本一致仍然报错，可以换另一个浏览器再试。

五、更新相关

  1. 问：如何检查更新？
     答：主页点击“检查更新”即可；也可以直接到项目发布页下载新版本。
